## 真实 Valor 现场验收

1. **启动环境。** 安装并授权 Valor，确认目标数据库存在，使用专用 `get -a11000` 会话；配置本机 `rcom.exe`。首先确认命令行 `rcom -a11000 "TST"` 可连接。
2. **错误包拦截。** 使用附件外层 A/B ZIP，界面应展示上述 4 个缺层错误，“确认并开始对比”不可用；不产生 RCOM 执行日志。
3. **同包比较。** 两侧选择同一份有效 ZIP，界面提示相同 SHA-256 警告但允许确认。实际运行后所有层的 `compare_layers` 答案应为 0，所有截图存在，报告总体一致。
4. **DemoCase 比较。** 分别压缩 DemoCase 中 A/B 文件夹后运行。核对 `import.log` 的全部状态为 `ok`，确认每层 A/B/Result 命名及截图。附件运行记录中单独阻焊层对比返回 65 网格，可作为参照；实际数值以当前现场执行和参数为准。
5. **截图边界和颜色。** 检查两侧图形完整显示，截图范围来自两个 LIMITS 的并集再外扩；显示槽 1/2/3 对应 A/B/Result，与本机 User 配色一致。2000 像素弹窗尺寸是否受 DPI/屏幕影响需在目标机器检查。
6. **失败路径。** 改错端口、使用无效数据库或断开连接，报告应显示执行失败；没有返回计数或没有截图时不可显示整体一致。重试前重新校验创建新任务。
7. **取消与复查。** 对耗时任务点击取消，检查报告和日志；若提示服务端状态不确定，在 Valor 中检查本次 Job/编辑器后再开始下一任务。
8. **导出。** 分别另存 HTML 和 ZIP，把 HTML 单独复制到另一目录离线打开，确认图片仍显示；检查 ZIP 中包含 JSON、命令、导入日志、LIMITS 和原始截图。

现场验收重点是 Valor 的真实行为和图形结果；通过软件模拟测试不代表这些项目已经验收通过。
